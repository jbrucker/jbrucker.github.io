## Create a Custom Github Home Page

*Big cludge for a simple thing.*

- Create a repo with the exact same name as your github account.
- In that repo create a README.md.  This file will be shown on your Github landing page.

For content ideas

- See [Awesome Github profile READMEs](https://github.com/abhisheknaiidu/awesome-github-profile-readme) for examples.
- Badges: <https://shields.io>.  You can run your own shields server using a Docker image.
- Don't write your *name* in README.md, it's already shown on left side of profile page.
